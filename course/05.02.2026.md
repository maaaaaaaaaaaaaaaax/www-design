## Getting started with LLMs in VS Code
LLMs can help you explore code, explain files, and draft changes.

**How to attach files**
- open the chat panel and use the attachment button
- pick files or folders you want the model to read
- ask questions that reference those files

**Different modes**
- ask mode: questions, explanations, quick guidance
- edit mode: apply changes to files
- agent mode: longer tasks across multiple files

Start small: ask for a summary of one file, then move to edits when needed.
Do microtasks: The AI model can easily be overwhelmed, try making a *step by step* plan and implement one idea after another. 
Do regular commits: Test the AI models change, if it is any good, commit it to Github. This way you can go back *step by step*.
