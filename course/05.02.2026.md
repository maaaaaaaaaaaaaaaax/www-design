## New feature: audio + video
We added support for audio and video files in the content system.

**How to include media**
- add your audio/video files inside a content folder or any subfolder
- keep them alongside your text or in their own media-only folder

**After adding new media**
Run: `./src/generate-file-array.sh`
This updates the file list so the site can load the new files.

### Sync your fork for the new feature
To get the audio + video changes, sync your fork with the main project.

**On GitHub**
- https://docs.github.com/de/pull-requests/collaborating-with-pull-requests/working-with-forks/syncing-a-fork

- click the Sync fork button
- update your fork if there are new commits

**After syncing**
- pull the latest changes to your local project, in your terminal type `git pull`

## Getting started with LLMs in VS Code
LLMs can help you explore code, explain files, and draft changes.

**How to attach files**
- open the chat panel and use the attachment button
- pick files or folders you want the model to read
- ask questions that reference those files

**Different modes**
- ask mode: questions, explanations, quick guidance
- edit mode: apply changes to files
- agent mode: longer tasks across multiple files

Start small: ask for a summary of one file, then move to edits when needed.
Do microtasks: The AI model can easily be overwhelmed, try making a *step by step* plan and implement one idea after another. 
Do regular commits: Test the AI models change, if it is any good, commit it to Github. This way you can go back *step by step*.
